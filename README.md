# online-healthcare
WebProject 
How to run the Project 
This online healthcare web application allows users to register using their email and complete email verification before logging in. After login, patients can create and manage their personal profiles. The system displays a list of available doctors and services so patients can easily book appointments. Online payment is required to confirm appointments securely. Doctors can manage patient appointments and upload medical reports through their dashboard. Patients can view and download their reports at any time. The platform also includes a “Share Thought” feature where users can provide feedback. Overall, the system ensures a smooth, secure, and user-friendly healthcare service experience.
